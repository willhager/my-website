Yellowjacket Racing Website

This is a club website that I built for the University of Rochester BAJA SAE team. It's built on a React + JS + MongoDB stack, with a schema-driven CMS architecture.

The frontend design specs were given to me by the BAJA club, but the implementation and backend was all done by me. The project taught me a lot about fullstack development and scalable architecture; it was the largest public-facing project that I had worked on at the time.

Runesworn

This is a work-in-progress dicerolling RPG video game being built in Godot. Though it's only partially finished, the final goal is to create a rogue-lite dungeon crawler with a combat system based on rolling dice.

The architecture is built entirely in Godot and has taught me quite a bit about project pacing, large-scale software design, and code modularity.

A limited alpha release + playable demo will hopefully be out soon!

CatGPT

This was a very simple project that I put together in just a few days. It's built on an idea that came to me in my sleep: mapping cosine similarity of an input to food-related terms, and using it to jokingly simulate animal behavior.

The project itself was quite simple, but I had a lot of fun putting it together; it was certainly a reminder of the joys of little projects.
